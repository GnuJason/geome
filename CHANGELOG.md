# Changelog

## 1.0.0 - 2026-09-17

- Initial local-development release of geome.
- HTTPS public IP geolocation through ipwho.is with bounded memory and timeouts.
- Compact, city, coordinate, JSON, and full output; offline help and version.
- Explicit missing values, validated coordinates, and stable exit statuses.
- Offline parser, formatter, HTTP fault, allocation, and CLI tests.
- GNU Make builds, sanitizer checks, man page, Debian packaging, and CI.

Public release remains blocked on owner-approved licensing, copyright
ownership, maintainer identity, and provider-terms review.
